# Project skills

This directory is reserved for **Cursor / CodeBuddy agent skills** used by this repo.

## Adding a skill

1. Create a subdirectory, e.g. `my-skill/`.
2. Add `SKILL.md` with YAML frontmatter (`name`, `description`) and instructions.
3. Keep skills focused; one skill = one workflow.

## Team catalog

For shared skills maintained by your organization, link to the internal skill registry here.

Do not commit secrets or environment-specific paths in skills.
