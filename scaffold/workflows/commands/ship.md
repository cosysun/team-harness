# Ship this change

Prepare the current work for review and merge.

## Steps

1. Run tests and linters for the active stack (see `AGENTS.md` or `CLAUDE.md`).
2. Ensure the diff is focused: one problem per PR.
3. Update `CHANGELOG` or release notes if the repo uses them.
4. Confirm `.harness.yaml` and AI context files are still accurate.
5. Draft a PR title and description using Conventional Commits style.

## Output

- PR title (one line)
- Summary (3 bullets)
- Test plan checklist
